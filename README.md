# Craft Image Prompts

一个用于编写和优化图像生成提示词的 Codex Skill。

它会把“生成一张很酷的图片”这类模糊想法，整理成包含主体、场景、动作、构图、镜头与光线、视觉风格和约束条件的可控提示词，适用于文生图提示词创作、扩写、诊断和变体生成。

## 使用方式

```text
$craft-image-prompts 帮我把这个想法写成可控的生图提示词：雨夜的上海弄堂，一个穿黄色雨衣的小女孩追着黑猫。
```

## 原帖来源

本 Skill 根据帖子[《如何写好一个生成图像的提示词》](https://linux.sb/topic/13965?p=1&floor=13)所介绍的方法整理并扩展，感谢原作者的经验分享。
